# Logos locais

- `c6.svg`: logo do C6 Bank, cópia disponível em https://commons.wikimedia.org/wiki/File:Logo_C6_Bank.svg (autor C6 Bank, fonte original www.c6bank.com.br, classificado como PD-textlogo). O servidor oficial bloqueou o download direto com HTTP 403.
