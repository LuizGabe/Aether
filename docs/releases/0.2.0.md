## Aether 0.2.0

Primeira distribuição desktop do Aether para Windows x64, com instalador e dependências de execução incluídas.

### Incluído

- Contas correntes, cartões e investimentos em áreas separadas.
- Histórico de transações com revisão, categorias, regras, horários e identificação do momento do dia.
- Recorrências com nomes e imagens personalizados.
- Conexão com a Pluggy, cofre de credenciais do Windows e dados locais em SQLite.
- Backup `.aetherbackup` protegido por senha e AES-256-GCM, restauração e retorno ao primeiro acesso.
- Inicialização otimizada, indicação real de carregamento e perfis isolados para desenvolvimento.

### Instalação

Baixe **Aether-v0.2.0-windows-x64-setup.exe**, execute o instalador e abra o Aether pelo menu Iniciar. O pacote inclui Eclipse Temurin Java 21 e o instalador offline do WebView2: não é preciso instalar um Java separado. Internet e configuração de uma aplicação Pluggy são necessárias para conectar bancos; o histórico importado e a restauração de backup funcionam localmente.

`Source code.zip` e `Source code.tar.gz` são o código-fonte, não o aplicativo instalável. SHA256SUMS.txt e BUILD-MANIFEST.json acompanham os arquivos para conferência de integridade e origem do build.

### Uso e privacidade

Uso pessoal, privado e não comercial permitido nos termos da licença incluída. Uso empresarial/profissional exige autorização específica. Componentes de terceiros mantêm suas próprias licenças.

O instalador não contém dados de usuários, credenciais ou backups. Guarde a senha de seus arquivos de backup: ela não é recuperável pelo Aether. Backups antigos SQLite não são criptografados retroativamente.

Distribuição sem certificado de assinatura de código nesta versão. O Windows pode identificar o publicador como não verificado. A validação desta entrega consiste no build; não foi executada uma nova bateria de testes nem um teste de instalação.
