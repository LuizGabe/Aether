# Aether — primeiros passos

1. Execute o instalador Aether para Windows x64 e abra o app pelo menu Iniciar. Java 21 está incluído; o instalador também leva o WebView2 necessário à interface.
2. Para trazer um histórico existente, escolha Restaurar um backup e informe a senha do arquivo protegido.
3. Para iniciar do zero, abra Configurações → Conexões, informe as credenciais da sua aplicação Pluggy e conecte um banco por vez. Senhas bancárias são informadas apenas no fluxo oficial do banco/Meu Pluggy.
4. Dados ficam em `%USERPROFILE%\Aether\data`, fora da pasta instalada. Atualizar o aplicativo preserva essa pasta.
5. Faça backups em Configurações → Dados e backup. Guarde a senha em um gerenciador; o Aether não consegue recuperá-la.
